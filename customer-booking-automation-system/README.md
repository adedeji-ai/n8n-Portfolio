## 🚀 Setup Instructions

### Prerequisites
- n8n instance (cloud or self-hosted)
- OpenAI API key
- HubSpot account
- Airtable account

### Installation Steps

1. **Import the Workflow**
   - Download the `workflow.json` file from this folder
   - In n8n, go to Workflows → Import from File
   - Select the downloaded JSON

2. **Configure Credentials**
   - Add your OpenAI API key
   - Connect your HubSpot account
   - Connect your Airtable base

3. **Update IDs**
   - Replace `[AIRTABLE_BASE_ID]` with your base ID
   - Replace `[HUBSPOT_PIPELINE_ID]` with your pipeline ID

4. **Test the Workflow**
   - Use the "Execute Workflow" button
   - Submit a test lead

5. **Activate**
   - Toggle the workflow to "Active"
